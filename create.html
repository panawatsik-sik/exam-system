สร้างข้อสอบออนไลน์

สำหรับอาจารย์ · กรอกข้อมูล อัปโหลดข้อสอบและรายชื่อ แล้วรับลิงก์สอบทันที

1. ข้อมูลวิชา

ตั้งชื่อให้จำง่าย จะแสดงบนหน้าสอบของนิสิต

2. ข้อสอบ

ดาวน์โหลด แม่แบบ Excel กรอกข้อสอบ แล้วอัปโหลดกลับมา

คลิกเพื่ออัปโหลดไฟล์ข้อสอบ (.xlsx)
ไฟล์ Excel ที่กรอกตามแม่แบบ

3. รายชื่อนิสิต (ไม่บังคับ)

อัปโหลดไฟล์รายชื่อจากระบบทะเบียน (ConsiderCourseChange) ได้โดยตรง ระบบจะตัดผู้ถอนรายวิชาและคำนวณชั้นปีให้อัตโนมัติ

คลิกเพื่ออัปโหลดรายชื่อ (.xlsx)
ใช้ไฟล์จากทะเบียนได้เลย หรือไฟล์ที่มีคอลัมน์ รหัส / ชื่อ / คณะ / สาขา

4. การตั้งค่าและรหัส

ตั้งรหัสให้จำได้ แต่นิสิตเดายาก (อย่าใช้รหัสส่วนตัวที่ใช้ที่อื่น)

เมื่อนิสิตสลับหน้าจอครบจำนวนนี้ ระบบจะล็อก นิสิตต้องให้อาจารย์มาใส่รหัสปลดล็อกจึงจะทำต่อได้

ดูชุดสอบที่เคยสร้างไว้ (ชุดสอบของฉัน)

สร้างข้อสอบสำเร็จ

เก็บลิงก์เหล่านี้ไว้ รหัสชุดสอบคือ

ลิงก์สำหรับนิสิต (ทำ QR Code จากลิงก์นี้)
ลิงก์ดูผล Dashboard (สำหรับอาจารย์)
รหัสปลดล็อก (จำไว้ใช้ปลดล็อกเครื่องนิสิต)
รหัสเข้า Dashboard
บันทึกข้อมูลนี้ไว้ก่อนปิดหน้า โดยเฉพาะรหัสชุดสอบและรหัสต่าง ๆ ถ้าลืมรหัส Dashboard จะดูผลไม่ได้
